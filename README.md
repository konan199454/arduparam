# ArduParam: ArduPilot на iPhone через ESP32

Вкладка **Політ**: авіагоризонт, курс, режим, ARMED/DISARMED, батарея, GPS, акселерометр, гіроскоп, вібрації та повідомлення ФК.
Вкладка **Параметри**: Full Parameter List з пошуком, редагуванням, збереженням у файл і завантаженням з файлу (з показом відмінностей).

## Що потрібно
- Будь-яка плата ESP32 (DevKit, ESP32-C3 SuperMini, S3).
- Arduino IDE 2.x.

## 1. Прошивка ESP32
1. Arduino IDE → File → Preferences → Additional boards manager URLs:
   `https://espressif.github.io/arduino-esp32/package_esp32_index.json`
2. Tools → Board → Boards Manager → встановити **esp32 by Espressif**.
3. Відкрити `ArduParam/ArduParam.ino`. Вгорі файлу задаються назва і пароль WiFi та піни RX/TX.
4. Вибрати свою плату й порт, натиснути Upload.

## 2. Підключення до польотника
| ESP32 | Польотник |
|---|---|
| GPIO17 (TX) | RX вільного UART |
| GPIO16 (RX) | TX того ж UART |
| GND | GND |
| 5V / VIN | 5V |

Параметри польотника (x = номер цього UART):
```
SERIALx_PROTOCOL = 2      (MAVLink2)
SERIALx_BAUD     = 115
```
Після цього перезавантажте ФК.

## 3. Телефон
1. Підключитися до WiFi **ArduParam** (пароль `12345678`). iPhone попередить про відсутність інтернету: залишайтеся підключеними.
2. У Safari відкрити **http://192.168.4.1** (або http://ardu.local).
3. «Поділитися» → «На початковий екран», щоб з'явилася іконка програми.

Статус угорі сторінки:
- зелена точка: усе працює;
- жовта: ESP32 на зв'язку, але ФК мовчить (переплутані TX/RX, не той SERIAL, інший baud);
- червона: телефон не підключений до WiFi ESP32.

## Android-планшет через USB-кабель (без ESP32)
Chrome на Android працює з USB напряму (WebUSB). Потрібні лише OTG-кабель або перехідник (USB-C планшета → USB польотника).
Налаштовувати ArduPilot не треба: USB за замовчуванням працює як MAVLink.

WebUSB працює лише на сторінках з **https**, тому програму треба один раз викласти в інтернет. Найпростіше через GitHub Pages (безкоштовно):
1. Зареєструватися на github.com і створити публічний репозиторій, наприклад `arduparam`.
2. Add file → Upload files: завантажити **вміст папки `web`** (index.html, sw.js, manifest.webmanifest, icon-192.png, icon-512.png).
3. Settings → Pages → Source: *Deploy from a branch*, гілка `main`, папка `/ (root)` → Save.
4. Приблизно за хвилину сторінка буде доступна за адресою `https://<ваш-логін>.github.io/arduparam/`.

На планшеті:
1. Відкрити цю адресу в Chrome → меню ⋮ → «Встановити застосунок» (або «Додати на головний екран»).
2. Після першого відкриття програма працює **без інтернету**.
3. Підключити польотник кабелем → натиснути **🔌 USB** → вибрати плату → дозволити доступ.
   Наступного разу програма підключиться сама, щойно вставите кабель.

Якщо пише, що порт зайнятий, закрийте QGroundControl та інші програми, які могли захопити USB.
Ця ж сторінка працює і на ПК в Chrome або Edge (там через Web Serial).

## Зміни сторінки
Сторінка редагується у `web/index.html`. Після змін запустіть `build_page.ps1`, щоб оновити `ArduParam/page.h`, і перепрошийте ESP32.
Демо без заліза: `web/index.html?demo` (імітація польотника).
